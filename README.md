# 🎡 Comsan Random Wheel (วงล้อสุ่ม Comsan)

> เว็บแอปพลิเคชันวงล้อสุ่มความน่าจะเป็น (Weighted & Equal Random Wheel) ที่ทันสมัย ลื่นไหล และปรับแต่งได้ครบวงจร พัฒนาด้วย **Vanilla JavaScript, HTML5 Canvas และ Modern CSS** โดยไม่ต้องพึ่งพา Library ภายนอก ออกแบบตามเอกลักษณ์และโทนสีของ **Comsan Design Language** (Vibrant Orange `#FF6B00` + Ultra-Bright Candy Pop Palette)

---

## 🌟 จุดเด่นและฟีเจอร์หลัก (Key Features)

### 1. 🎯 ระบบฟิสิกส์วงล้อและแอนิเมชันระดับสูง (Smooth Wheel Engine)
- **High-DPI Crisp Canvas Rendering**: วงล้อคมชัดทุกความละเอียดหน้าจอ (รองรับ Retina Display / 4K)
- **Quartic Ease-Out Physics**: แอนิเมชันการหมุนและชะลอความเร็วที่นุ่มนวล สมจริง และน่าตื่นเต้น
- **Realistic Web Audio Sound FX**: เสียงคลิก Ticking ตามจังหวะเข็มชี้กระทบหมุดวงล้อ และเสียงฉลองเมื่อได้ผลลัพธ์
- **Confetti Celebration**: พลุกระดาษฉลองหลากสีสันสดใสเมื่อวงล้อหยุดหมุน
- **Multi-Touch & Tap to Spin**: แตะที่ตัววงล้อ, โลโก้ตรงกลาง (Center Hub) หรือกดปุ่มหมุนด้านข้างเพื่อสุ่มได้ทันที

### 2. 🎛️ โหมดการจัดการความน่าจะเป็น (Probability Modes)
- **โหมดเรียบง่าย (Simple Equal Mode - ค่าเริ่มต้น)**:
  - หน้าจอคลีนตา ซ่อนช่องกรอกเปอร์เซ็นต์
  - ระบบจะคำนวณและแบ่งโอกาสเท่ากันทุกช่อง ($100 / N$ %) ให้อัตโนมัติทุกครั้งที่เพิ่มหรือลบรายการ
- **โหมดกำหนดโอกาสเอง (Custom Weighted Mode)**:
  - เปิดใช้งานในเมนูตั้งค่า เพื่อพิมพ์กำหนด % โอกาสของแต่ละรายการได้อย่างอิสระ
  - มีแถบตรวจสอบผลรวม 100% พร้อมปุ่ม **"แบ่งเท่า"** และ **"ปรับ 100%"** อัตโนมัติ

### 3. 🎨 สีสันสดใสแบบ Ultra-Bright Candy Pop & Color Picker
- พาเลตสีสดใส คอนทราสต์สูง 16 เฉดสีสด ป้องกันสีซ้ำและกลืนกัน
- Color Picker Popover คลิกที่จุดสีในแต่ละแถวเพื่อเปลี่ยนสีได้ทันที

### 4. 🤫 ระบบสั่งผลลับ (Secret Bias Hotkey)
- **สั่งผลลัพธ์ล่วงหน้าได้อย่างแนบเนียน**: ผู้ควบคุมสามารถกดปุ่มตัวเลข **`1` ถึง `9`** บนคีย์บอร์ดก่อนกดหมุน เพื่อล็อกให้ผลลัพธ์ตกที่รายการลำดับที่ 1-9 ตามต้องการ
- **Auto-Reset**: รีเซ็ตกลับเป็นโหมดสุ่มปกติทันทีที่วงล้อเริ่มหมุน
- **Cancel Hotkey**: กดปุ่ม **`0`** หรือ **`Escape`** เพื่อยกเลิกคำสั่งลับ
- การหมุน เสียงคลิก และความเร็วจะเหมือนการสุ่มปกติ 100% คนดูไม่มีทางสังเกตได้

### 5. ⚙️ การตั้งค่าขั้นสูง (Settings Modal)
- **ซ่อนเปอร์เซ็นต์บนวงล้อ**: ซ่อนตัวเลขโอกาส `(%)` ออกจากวงล้อ ให้แสดงเฉพาะชื่อรายการ
- **ขนาดช่องบนวงล้อเท่ากันทุกช่อง**: แสดงขนาดความกว้างของทุกช่องบนวงล้อเท่ากัน ($360^\circ / N$) แม้ % โอกาสจะไม่เท่ากัน (ระบบยังคงคำนวณผลตาม % จริงอย่างแม่นยำ)
- **ลบตัวเลือกที่สุ่มได้ออก (Remove Winner)**: เมื่อสุ่มได้รายการใด จะตัดรายการนั้นออกจากวงล้อและปรับ % ให้อัตโนมัติ
- **ปรับระยะเวลาการหมุน**: ตั้งค่าความเร็วได้ตั้งแต่ `2.0s` ถึง `10.0s`
- **เปิด/ปิดเสียงเอฟเฟกต์ & พลุกระดาษ**

### 6. 📜 ระบบประวัติและสถิติ (History & Analytics)
- บันทึกผลการสุ่ม 10 ครั้งล่าสุด พร้อมเวลาและเปอร์เซ็นต์โอกาส
- แถบสรุปสถิติผลลัพธ์ (Summary Stat Pills) เช่น `A x4 (40%)`
- ปุ่มล้างประวัติการสุ่ม (พร้อมการยืนยัน)

### 7. 🧭 Client-Side URL Routing & คีย์ลัด (Shortcuts & UX)
- **URL Hash Routes**:
  - `#/wheel` หรือ `#/` $\rightarrow$ หน้าวงล้อสุ่ม
  - `#/history` $\rightarrow$ หน้าประวัติการสุ่ม
  - `#/settings` $\rightarrow$ เปิดหน้าต่างตั้งค่า
- รองรับปุ่ม Back / Forward ของเว็บเบราว์เซอร์ และ Direct Deep-linking
- **คีย์ลัดอัจฉริยะ**:
  - **`Ctrl + Enter`** (หรือ **`Cmd + Enter`**): สั่งหมุนวงล้อได้ทันทีจากทุกจุด
  - **`Spacebar` / `Enter`**: สั่งหมุนวงล้อเมื่อไม่ได้อยู่ในช่องพิมพ์ข้อความ
  - **Enter ขณะพิมพ์ชื่อ**: โฟกัสไปยังช่องถัดไปอัตโนมัติ
  - **วางข้อความหลายบรรทัด (Multi-line Paste)**: แยกเป็นไอเทมให้อัตโนมัติพร้อมปรับ % เท่ากัน
- บันทึกข้อมูลลง **LocalStorage** อัตโนมัติ ข้อมูลไม่หายเมื่อรีเฟรช

## 🚀 วิธีการติดตั้งและรันใช้งาน (Getting Started)

โปรเจกต์นี้เป็น Pure Static Web Application สามารถเปิดใช้งานได้ทันทีโดยไม่ต้อง Build หรือติดตั้ง Dependency ใดๆ:

### วิธีที่ 1: เปิดไฟล์โดยตรง
- ดับเบิ้ลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานบน Web Browser (Chrome, Edge, Safari, Firefox)

### วิธีที่ 2: รันผ่าน Local Web Server (แนะนำ)
```bash
# ด้วย npx serve
npx serve .

# หรือด้วย Python
python -m http.server 3000

# หรือด้วย PHP
php -S localhost:3000
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

## ⌨️ ตารางคีย์ลัด (Keyboard Shortcuts Summary)

| คีย์ลัด | คำอธิบายการทำงาน |
|---|---|
| **`Ctrl + Enter`** / **`Cmd + Enter`** | สั่งหมุนวงล้อทันที (ใช้งานได้ทุกที่ แม้กำลังพิมพ์ข้อความ) |
| **`Spacebar`** / **`Enter`** | สั่งหมุนวงล้อ (เมื่อไม่ได้โฟกัสอยู่ในช่องกรอกข้อความ) |
| **`1` – `9`** | สั่งผลลัพธ์ลับ (Secret Bias) ให้รอบถัดไปตกที่รายการลำดับที่ 1-9 |
| **`0`** / **`Escape`** | ยกเลิกคำสั่งผลลัพธ์ลับ |
| **`Enter` (ในช่องชื่อ)** | สลับโฟกัสไปยังช่องพิมพ์รายการถัดไป |
