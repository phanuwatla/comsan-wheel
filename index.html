วิธีใช้งาน

1. การหมุนวงล้อ
  • แตะหรือคลิกที่ ตัววงล้อ หรือ โลโก้ตรงกลาง เพื่อเริ่มสุ่ม
  • คลิกที่ปุ่มสีส้ม "สุ่ม" ที่แผงด้านข้าง
  • กดคีย์ลัด Ctrl + Enter (หรือ Cmd + Enter) ได้จากทุกที่
2. การจัดการรายการ
  • เพิ่มรายการ: กดปุ่ม + เพิ่มรายการ หรือพิมพ์ในช่องชื่อแล้วกด Enter
  • วางข้อความหลายบรรทัด: คัดลอกข้อความแล้วกด Paste ระบบจะแยกเป็นแต่ละรายการให้อัตโนมัติ
  • เปลี่ยนสี: คลิกที่จุดสีด้านหน้ารายการ เพื่อเลือกเปลี่ยนสีจากพาเลตสดใส
  • เรียงลำดับ: ลากไอคอน ⠿ ด้านซ้ายสุดเพื่อสลับตำแหน่งรายการ
3. โหมดความน่าจะเป็น (Probability)
  • โหมดเท่ากัน (Default): หน้าจอเรียบง่าย แบ่งโอกาสสุ่มให้ทุกรายการเท่ากัน 100/N % อัตโนมัติ
  • โหมดกำหนด % เอง: เปิดใช้งานได้ในเมนูการตั้งค่า เพื่อพิมพ์กำหนด % โอกาสของแต่ละรายการ
4. ตัวเลือกการตั้งค่าขั้นสูง
  • ซ่อนเปอร์เซ็นต์บนวงล้อ: แสดงเฉพาะชื่อรายการบนวงล้อ
  • ขนาดช่องเท่ากันทุกช่อง: แสดงความกว้างเท่ากันทุกช่อง แม้ว่า % โอกาสจะไม่เท่ากัน
  • ลบตัวเลือกที่สุ่มได้ออก: ตัดรายการที่ชนะออกจากวงล้ออัตโนมัติ
  • ปรับระยะเวลาการหมุน: ตั้งเวลาได้ตั้งแต่ 2.0 – 10.0 วินาที
5. คีย์ลัดบนแป้นพิมพ์

กำหนดเปอร์เซ็นต์โอกาสเอง (Custom %) เปิดเพื่อพิมพ์กำหนด % โอกาสของแต่ละรายการแยกกัน (หากปิด ทุกรายการจะได้รับโอกาสเท่ากันเสมอ)
ซ่อนเปอร์เซ็นต์บนวงล้อ แสดงเฉพาะชื่อรายการบนวงล้อ โดยซ่อนตัวเลขโอกาส (%)
ขนาดช่องบนวงล้อเท่ากันทุกช่อง แสดงความกว้างของทุกช่องเท่ากันทั้งหมด แม้ว่า % โอกาสจะไม่เท่ากัน (คำนวณผลตาม % จริง)
